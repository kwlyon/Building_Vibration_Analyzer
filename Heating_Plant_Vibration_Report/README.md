# Heating-Plant Vibration Report

This folder contains a concise report based on the 20 spectra in the
`Manual Analysis` folder.

- `report/Heating_Plant_Vibration_Report.pdf` — finished report
- `report/Heating_Plant_Vibration_Report.tex` — editable source
- `figures/` — report figures in PDF and PNG formats
- `analysis/` — extracted spectra, analysis results, summary tables, metadata,
  and the scripts used to reproduce the analysis and figures
- `tmp/pdfs/` — rendered report pages used for visual quality assurance

The analysis excludes frequencies below 2 Hz. The principal plant-associated
lines are 29.8, 98.7, 101.7, and 120.0 Hz.
